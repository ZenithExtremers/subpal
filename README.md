# SubPal（サブパル）

サブスクの支払い・更新日・無料期間をまとめて管理するPWA。ペンギンの「パル」が解約忘れを知らせます。

- 人気サービスのプリセットからタップで登録（解約・管理ページへのリンク付き）
- 毎月・毎年・毎週／Nか月ごとの支払いに対応、支払日は自動で次回へ更新
- 支払い前・無料期間終了前の通知（アプリ起動時＋対応端末ではバックグラウンド）
- カレンダー（.ics）書き出しで確実なリマインド
- 月額・年額・1日あたりの集計、カテゴリ別グラフ、12か月の支払い予定
- 一時停止・解約済みの管理と「解約で節約できた額」
- JSONでバックアップ／復元、ダークモード、オフライン対応

データは端末内（localStorage）にのみ保存されます。
